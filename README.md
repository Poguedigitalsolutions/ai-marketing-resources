## Core Principles

### Human Before Machine

AI should support human judgment, creativity, and decision-making.

### Voice Before Volume

Publishing more content is not useful if it sounds generic or disconnected from the brand.

### Context Before Creation

Better inputs produce better outputs. AI should understand the audience, offer, values, goals, history, and communication style before creating content.

### Approval Before Execution

Important communications should remain subject to human review.

### Systems Create Consistency

Documented processes make it easier to maintain quality, train others, and improve over time.

### Protect What Should Remain Private

Confidential client information, passwords, credentials, proprietary data, and sensitive personal details should not be placed into public AI systems or repositories.
